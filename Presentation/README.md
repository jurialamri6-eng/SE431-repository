# SE431 presentation

SE431_Presentation.pptx is an editable 14-slide deck based on the University of Prince Mugrin template. The cover uses the department shown in the assignment and labels this version as a review copy. It reads team and repository fields from Documentation/review_status.json. The team has not supplied the roster or confirmed a repository link.

Four slides give the current architecture, the copy-count workflow, the storage adapters and the shared borrowing domain a full slide each. Their editable sources are Pages 3–6 in Drawio_Diagrams/SE431_Architecture.drawio. The preview PDF lets reviewers check the slides without PowerPoint. Slide 11 shows the three measured versions and the verified test count. Slide 12 summarizes the task register in report Appendix C.

Build the presentation from this folder with the project environment and build_deck.py. Export the preview with export_preview.py.
