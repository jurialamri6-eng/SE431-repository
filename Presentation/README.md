# SE431 presentation

SE431_Presentation.pptx is an editable 14-slide deck based on the University of Prince Mugrin template. The project cover uses the department shown in the assignment. Team number, names, university IDs and instructor are editable fields.

Four slides give the current architecture, the copy-count workflow, the storage adapters and the shared borrowing domain a full slide each. Their editable sources are Pages 3–6 in Drawio_Diagrams/SE431_Architecture.drawio. The preview PDF lets reviewers check the slides without PowerPoint.

Build the presentation from this folder with the project environment and build_deck.py. Export the preview with export_preview.py.
